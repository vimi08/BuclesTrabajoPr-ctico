# Trabajo Práctico Nº2 – Bucles y Estructuras Condicionales

Este proyecto contiene una serie de ejercicios prácticos en **JavaScript** para afianzar el uso de **bucles** (`for`, `while`, `do...while`) y **estructuras condicionales** (`if`, `else if`, `else`, `switch`).  
Cada ejercicio está implementado en un archivo independiente dentro de la carpeta `js/`.

---

## 📌 Contenido de los ejercicios

### 1. Edad
- Solicitar la edad al usuario.
- Determinar si es mayor o menor de edad.

### 2. Nota
- Solicitar una nota numérica.
- Mostrar si el alumno está aprobado, desaprobado o promocionado.

### 3. Cadenas
- Solicitar una cadena de texto.
- Mostrar su longitud y contenido.

### 4. Números
- Solicitar un número.
- Mostrar si es positivo, negativo o cero.

### 5. Letra DNI
- Calcular la letra correspondiente a un número de DNI.
- Usar condicionales para determinar la letra.

### 6. Pirámide
- Mostrar una pirámide de números con bucles.

### 7. Pirámide Inversa
- Mostrar la pirámide invertida con bucles.

### 8. Pirámide Consecutiva
- Mostrar una pirámide con números consecutivos.

### 9. Múltiplos
- Mostrar los múltiplos de un número ingresado.

### 10. Tabla de Multiplicar
- Solicitar un número.
- Mostrar su tabla de multiplicar del 1 al 10.

### 11. Mayor Edad
- Solicitar varias edades.
- Determinar la mayor.

### 12. Número Aleatorio
- Generar un número aleatorio.
- Mostrarlo por pantalla.

### 13. Texto Mayúscula
- Convertir un texto ingresado a mayúsculas.

### 14. Cadena con Guiones
- Mostrar cada carácter de una cadena separado por guiones.

### 15. Vocales
- Contar cuántas vocales tiene una cadena.

### 16. Cadena Invertida
- Mostrar una cadena invertida.

### 17. Primera Vocal
- Mostrar la primera vocal encontrada en una cadena.

---

## 🚀 Tecnologías utilizadas
- **JavaScript (ES6+)**
- **HTML5** para la estructura básica.
- **CSS / Bootstrap** (opcional) para dar estilo a las salidas.
